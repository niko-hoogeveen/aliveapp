# Design Assets

Place exported Figma frames here for agent reference.

## Required Exports

Export the following screens from Figma at 2x resolution:

### Dependent Screens
- `dependent-home.png` - Main "I'm Okay" button screen
- `dependent-widget.png` - Lock screen widget design
- `dependent-help.png` - Help/emergency screen

### Guardian Screens
- `guardian-dashboard.png` - Dependent list/status view
- `guardian-detail.png` - Individual dependent detail
- `guardian-schedule.png` - Check-in schedule configuration
- `guardian-alerts.png` - Alert/notification history

### Shared Screens
- `onboarding-flow.png` - Welcome and role selection
- `settings.png` - Settings screen
- `subscription.png` - Premium upgrade screen

## Design Tokens

After exporting screens, also export design tokens to `design-tokens.json` including:
- Color palette (hex values)
- Typography scale
- Spacing values
- Border radii
- Shadow definitions
